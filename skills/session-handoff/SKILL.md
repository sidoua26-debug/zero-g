# /session-handoff (stub)

Multi-session work or session ending:

1. Gather session context: discussed decisions, completed work, pending tasks.
2. Write `handoff.md` with sections:
   - **Discussed**: Key decisions, constraints, and trade-offs agreed upon.
   - **Done**: Work completed, verified vertical slices, and passing gates.
   - **Next**: Immediate next steps, pending tests, or remaining implementation items.
   - **References**: File links (`file#L10-L20`), documentation, and command references.
3. Recommend starting a fresh session if context is large.
